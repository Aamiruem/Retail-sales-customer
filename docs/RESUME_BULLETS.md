# Resume Project Entry

## Retail Sales & Customer Insights Analytics Dashboard — Major Project

**Tech Stack:** Python, SQL, SQLite, Excel, Power BI, Pandas, NumPy, Power Query, DAX, Matplotlib, Seaborn, Streamlit

- **Data Integration & Quality:** Integrated 4,224 synthetic retail records from CSV, Excel and SQL sources; cleaned missing values, duplicates, invalid dates, data types and outliers to create 4,180 validated transactions and a SQL star schema.
- **Analysis & KPIs:** Performed EDA, correlation, RFM customer segmentation, discount, return and target analysis; calculated ₹160.1M revenue, ₹41.3M profit, 25.8% margin, 3,922 orders and an 8.8% return rate.
- **Dashboard Delivery:** Built a formula-driven Excel dashboard, Power BI-ready model with Power Query and DAX, interactive Streamlit dashboard, SQL reports, data dictionary and automated tests.
